# 09 - チームロールサイコロ

**ビルド日**: 2026-11-03
**カテゴリ**: fun
**slug**: team-role-dice

## 概要
チームメンバー名を登録し「サイコロを振る」ボタンでランダムに役割を割り当てる。ミーティングやワークショップでの役割分担をフェアに決定できる。

## 機能
- メンバー追加・削除（localStorage で永続保存）
- 定義済み役割7種: モデレータ/タイムキーパー/書記/ファシリテータ/レビュアー/プレゼンター/デビルズアドボケイト
- カスタム役割の追加・削除
- ランダム割り当てボタンでCSSアニメーション付き結果表示
- 未割当役割の表示
